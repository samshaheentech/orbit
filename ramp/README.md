# Ramp

Your coding ramp. Each folder is one problem: read `README.md`, write your solution in `solution.py`, run `python3 test_<slug>.py` until it passes. The working fires check open problems, mark passes, and bring struggles back with one hint. Passed problems return a week later with the same tests for retention.

Rules you set: no AI assistance while solving, function plus tests at the bottom, you write all the code.
